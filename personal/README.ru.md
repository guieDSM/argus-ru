# Русская сборка Argus для установленного приложения

Сборка из [официальных исходников Argus](https://github.com/Ray-lea/Argus)
включает русский перевод ветки `main`. Версия содержит метку `personal-ru` и SHA
коммита. Лицензия — AGPL-3.0-or-later, исходные уведомления сохранены.

Сборка и проверки выполняются в GitHub Actions. Приватный черновик релиза
`personal-ru-2` содержит `Argus-RU-Windows-x64.zip`, контрольную сумму и сведения
об исходниках. `results.json` подтверждает 12 проверок страниц и диалогов.
Снятие изображений через Windows.Graphics.Capture недоступно на сервере CI;
проверки используют встроенную инспекцию настоящего окна Argus.

## Завершение установки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\personal\complete-upgrade.ps1
```

Windows запросит UAC. После подтверждения `upgrade-installed.ps1`:

1. Проверит SHA-256 закреплённой сборки.
2. Сохранит установленный `.exe`, свежие настройки, положение окна, историю
   и существующую задачу запуска от администратора.
3. Завершит только экземпляры Argus текущего пользователя и сеанса.
4. Заменит `Program Files\Argus\argus.exe` русской сборкой.
5. Установит `language: ru-RU` и сохранит включённую проверку обновлений.
6. Обновит уже выданную авторизацию запуска штатной командой Argus,
   проверит доступность встроенного обновления и запустит приложение.

Остальные параметры сохраняются, включая выбранные пользователем интервалы
0,5 секунды, боковую навигацию, сортировку, графики и автозагрузку. Служба,
драйверы и замена системного Диспетчера задач этим скриптом не включаются.

Состояние операции: `%LOCALAPPDATA%\Programs\Argus-RU\upgrade-status.json`.
Резервные копии: соседняя папка `backups`. Пока UAC не подтверждён,
существующее приложение не заменяется.

## Последующие обновления

Сохраняется штатный механизм Argus: автоматическая проверка и загрузка новых
официальных версий с проверкой подписи, затем подтверждение установки в
приложении. Собственные ключи подписи и источники обновлений не подменяются.

Настройки находятся отдельно в `%APPDATA%\dev.argus.taskmanager` и сохраняются
при обновлении. Выбор `ru-RU` сохраняет русский язык в версиях, где он
поддерживается. Перевод уже входит в официальный `main`; наличие русского
в будущих выпущенных версиях определяет разработчик проекта.

## Замена системного Диспетчера задач

Замена включена штатными командами Argus через `enable-task-manager.ps1`.
Установлена необходимая служба `ArgusPrivileged`; встроенная проверка запуска
и интерфейса прошла, запись восстановления активна. Запуск Windows
`taskmgr.exe` проверен: открывается Argus, новый процесс штатного Диспетчера
задач не появляется. Этот же системный вход используется для `Ctrl+Shift+Esc`.

Состояние операции: `%LOCALAPPDATA%\Programs\Argus-RU\taskmgr-status.json`.
Вернуть стандартный Диспетчер задач можно в Argus:
«Параметры → Разрешения → Заменить Диспетчер задач» — выключить.
Независимый инструмент восстановления находится в
`C:\Program Files\Argus Privileged\argus-taskmgr-recover.exe`.
