# Личная русская сборка Argus

Собирается из исходников [Ray-lea/Argus](https://github.com/Ray-lea/Argus),
включающих официальный русский перевод интерфейса, области уведомлений,
настройки при первом запуске и сообщений приложения. Лицензия — AGPL-3.0-or-later.
Это личная сборка ветки разработки, версия содержит метку `personal-ru` и SHA коммита.

Тяжёлая сборка и проверка интерфейса выполняются в GitHub Actions вручную через
workflow **Personal Russian build**. Приватный черновик релиза `personal-ru-*`
содержит архив **Argus-RU-Windows-x64.zip** с приложением, контрольной суммой,
сведениями об исходниках и установочным скриптом. Файл **results.json** в том же
черновике содержит результат проверки страниц и диалогов интерфейса на русском.
Снимки окна проверяются после установки: захват через Windows.Graphics.Capture
недоступен на используемом сервере GitHub Actions.

## Установка для текущего пользователя

После распаковки артефакта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Приложение устанавливается в `%LOCALAPPDATA%\Programs\Argus-RU`.
Создаются ярлыки «Argus (Русский)» на рабочем столе и в меню «Пуск».
Существующие настройки и история сохраняются; перед изменением настроек скрипт
создаёт резервную копию. Язык явно устанавливается в `ru-RU`, проверка обновлений
для этой личной сборки выключается. Новую сборку можно установить тем же скриптом.
Обновления других программ и Windows не затрагиваются.

Скрипт не запрашивает права администратора, не устанавливает службы или драйверы
и не подменяет системный Диспетчер задач. Официальная установка Argus в
`Program Files` сохраняется. Для открытия русской сборки используйте созданный ярлык.

Для возврата к официальной версии завершите русскую сборку, восстановите
`settings.json` из созданной резервной копии и откройте прежний Argus.
