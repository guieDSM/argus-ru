Русская сборка [guieDSM/argus-ru](https://github.com/guieDSM/argus-ru)
на основе [Ray-lea/Argus](https://github.com/Ray-lea/Argus).

Для Windows 10/11 x64 доступны два варианта:

- **`Argus-RU-setup.exe` — установщик, рекомендуется.** Устанавливает Argus
  в `Program Files`, создаёт ярлыки и запись для удаления приложения.
  Для установки Windows запросит права администратора.
- **`Argus-RU.exe` — запуск без установки.** Скачайте файл в отдельную папку
  и откройте его. Встроенное обновление для этого варианта недоступно.

Русский язык выбирается по языку Windows. Его также можно включить
в параметрах Argus. Настройки существующей установки сохраняются;
эта сборка использует те же папки данных, что и официальный Argus.

В установщике сохранён штатный механизм обновления из официального проекта
Ray-lea/Argus с проверкой его подписи. Последующее обновление заменит эту
сборку официальной версией. Новые сборки форка можно скачать из его Releases.

Перед публикацией GitHub Actions выполняет общие проверки проекта, проверяет
тихую установку и удаление, распознавание установленной и переносимой копий,
а также русский интерфейс через инспекцию окна. `interface-checks.json`
содержит результаты проверки интерфейса; снимки экрана в CI не создаются.

`SHA256SUMS.txt` содержит SHA-256 обоих `.exe`, `build-info.json` — версию,
коммит исходников и ссылку на сборку. Лицензия AGPL-3.0-or-later и уведомления
о сторонних компонентах приложены к релизу.
